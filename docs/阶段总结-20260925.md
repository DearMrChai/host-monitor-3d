## 一、项目是什么

零构建的原生 ESM + three.js 监控墙：一屏看到家里/办公室几台真机谁在忙。
**1 世界单位 = 1 毫米**；只经 `src/three.mjs` 用 three，`three/examples/` 一律禁（含 `OrbitControls`、`UnrealBloom`）。
两个页面：`monitor-wall.html`（墙，1034 行）与 `silhouette-shelf.html`（剪影架，620 行，只验包围盒与不闪）。
跑法三条命令见 README「三条命令跑起来」。

## 三、一条数据的完整链路（"142 屏上那圈为什么是黄的"）

1. `serve.mjs` 每轮（默认 3 s）对清单里每台没藏起来、填了地址+用户名的机器发一次 SSH → 一帧 `{cpuPct, gpus[], gpu, memUsedMb, memTotalMb, …}`，写进内存帧缓存，并往 `probe.log` 追加一行
   `时间 OK 主机 cpu= gpu= mem=`（`framePeek()`，双卡逐张取 max；FAIL 行只有错误首行，**不记用户名口令**）。
2. 页面每 2 s 拉 `/api/frames` → 每台的 `pct = max(cpu, 各卡 gpu)`、内存只用来越线抬档 ⇒ **口径 B**，判据在 `src/model.mjs` 的 `gradeOf()`，阈值 35 / 70。
3. 档位 ⇒ `STATES` 那一行的 `{color, amplitude, speed, interval}`：**IDLE 绿 8 / 3.0 s / 0.6，ACTIVE 黄 16 / 2.0 s / 0.85，ALERT 红 30 / 1.2 s / 1.2**（六根关联滑杆能改，初值不许漂——`verify-grade` + `verify-ripples` 钉着）。
4. `src/ground.mjs` 的 `stepRipples(t)` 按那一档的节拍 `addRipple(x, z, color, amplitude, speed)`，并 `noteRipple()` 记一条取证（每档只留第一圈，落 `localStorage` 键 `hm3d.rippleEvidence.v1`，开页读回）。
5. 手动撒环那个钩子 `rippleKick` 是**另一个调用点**，屏上真正在荡的走 3~4——这一区分就是清账1 的全部内容。
